## Owner browser test A — Worker cannot enter Company portal

1. Start the application with `npm run dev`.
2. Sign in at `http://localhost:3000/worker/login`.
3. Confirm the Worker dashboard opens.
4. Paste `http://localhost:3000/company/dashboard` directly into the address bar.
5. Confirm Company content never appears and the access-denied boundary is shown.
6. Return to the Worker dashboard and confirm the valid Worker session still works.
7. Sign out.

Expected: copied Company URL is denied without switching, corrupting or terminating the valid Worker session.

## Owner browser test B — Company cannot enter Worker portal
