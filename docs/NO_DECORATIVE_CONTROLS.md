# No Decorative Controls

The Worker Dashboard renders active controls only when they have a real destination and behavior in this build unit:

- Copy Worker ID
- View public profile when explicitly permitted
- notification deep links
- Exit portal
- Sign out

Profile, evidence, assessment, interview, credential, reassessment, appeal and payment actions remain inactive implementation boundaries until their dedicated modules provide server commands, authorization, state validation, loading, success, failure, audit and tests.
