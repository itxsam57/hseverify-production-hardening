# Security Policy

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities or exposed credentials. Contact the repository owner privately with:

- the affected route or component;
- reproduction steps;
- expected and observed behavior;
- any evidence needed to assess impact.

Do not include real worker identity documents, credentials, assessment answers or personal data in a report.

## Current foundation status

The Worker Dashboard currently uses environment-gated demonstration authentication and non-persistent demonstration data for isolated development only. Both demo flags must remain disabled in production until approved authentication, persistence, audit and provider adapters are connected.
